# Fundamentals of Agentic AI  

This repository contains my notes and experiments on the **Fundamentals of Agentic AI**.  
It covers core concepts like prompt engineering, sampling techniques, and safe prompting.  

## 📂 Contents  
- **Prompt Engineering** – Basics of writing effective prompts  
- **Temperature** – Controlling randomness in responses  
- **Top-k Sampling** – Limiting token choices to the top *k* options  
- **Top-p (Nucleus Sampling)** – Dynamic probability-based sampling  
- **Safe System Messages** – Guidelines for handling sensitive data  
- **Chain of Thought Prompting** – Step-by-step reasoning in AI

This repo is for practice and learning.
